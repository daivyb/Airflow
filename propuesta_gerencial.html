Contexto y Desafío Actual

El Problema (Fragmentación de Datos)

  • Múltiples fuentes aisladas: Los datos operativos (Ejecuciones, Presupuesto, Saldo, etc) residen en una Base de Datos Financiera, pero la data geográfica depende de recolección manual desde la web VTrack.
  • Procesos manuales: El equipo invertía tiempo en descargar reportes web, cruzar excels y tratar de consolidar la información financiera contra las regiones mediante scripts o de forma manual.
  • Riesgo de errores: Manipulación manual de archivos locales que propiciaba errores humanos, desajustes en el cruce de datos y retrasos operativos para los analistas.

La Solución Implementada (Prueba de Concepto)

  • Flujo 100% Automatizado: Un sistema central que lee directamente de la Base de Datos Financiera, navega VTrack autónomamente para extraer regiones, cruza la data y la sube al Data Warehouse principal.
  • Robótica Web Moderna: Uso de navegadores simulados invisibles (Playwright) que operan VTrack de manera silenciosa para complementar la información dura de la BD Financiera.
  • Consistencia y Trazabilidad: Si el sistema detecta un fallo, se detiene, reintenta y alerta, asegurando que los tableros gerenciales nunca consuman datos a medias o desincronizados.

Beneficios Clave y Retorno de Inversión (ROI)

Eficiencia Operativa

El proceso pasa a operar de forma autónoma. Al programarse de madrugada, garantiza que a las 8:00 AM los tableros de Inteligencia de Negocios ya tengan la información financiera consolidada con la data geográfica.

Gobernanza de Datos

Se erradican los errores de tipeo o cruce manual de Excel. Se asegura que la información unificada viaje bajo estrictas reglas de negocio hacia el Data Warehouse creando una "Única Fuente de Verdad".

Escalabilidad

Al usar Apache Airflow, Profonanpe ahora posee una plataforma robusta. Mañana, integrar procesos de RRHH, Sistemas Contables o ERPs tomará una fracción del tiempo, bajo la misma herramienta unificada.

Requerimientos y Presupuesto

Inversión en Software y Licencias: $0 USD. El desarrollo utiliza tecnologías empresariales de código abierto (Python, Apache Airflow, Docker, Playwright).

Opción A: Servidor en la Nube (AWS, Azure) — Recomendada

Hardware / Servicio Detalle y Beneficios Costo Mensual Estimado
Servidor Virtual (VM) 4 vCPUs, 8 GB RAM, 50 GB SSD (Sistema Linux Ubuntu). ~$50 - $80 USD
Beneficios Garantía de funcionamiento del 99.9% (Uptime), respaldos automáticos, delegación de mantenimiento de hardware al proveedor de nube, máxima seguridad y aislamiento.

Opción B: Servidor Local (Centro de Datos Profonanpe)

Hardware / Servicio Detalle y Beneficios Costo Mensual Estimado
Máquina Virtual Local Mismas especificaciones (4 vCPUs, 8 GB RAM) desplegadas en los servidores que ya posee la institución. Requiere acceso a internet. $0 USD (Costo Hundido)
Beneficios Aprovecha la infraestructura existente, el tráfico de datos no viaja por internet, control total por parte del área interna de Tecnología.
